## 为什么马来站要家宽 IP，双 ISP 到底指什么

TikTok 判断账号环境，很大一部分看 IP 属性。数据中心 IP 的 ASN 挂在机房或云厂商名下，平台一查就知道不是本地宽带用户，这类 IP 注册的账号默认权重低。家宽 IP 的 ASN 和 Company 两栏都指向当地运营商，平台难以把你和真实住宅用户区分开。

双 ISP 说的是这两个维度都对得上：ASN 是 ISP，Company 也是 ISP。只对一个，或者 ASN 看着像 ISP、Company 却挂在某个 hosting 公司名下，纯净度就打折。到手第一件事是查这两个字段，商家页面写得多好听都不算数。
